# homebrew-tap

Homebrew formulae for [jdpalmer](https://github.com/jdpalmer)’s personal projects.

## Usage

```bash
brew tap jdpalmer/tap
brew install <formula>
```

Or install in one step without a prior tap:

```bash
brew install jdpalmer/tap/<formula>
```

## Formulae

| Formula | Description |
| --- | --- |
| [`modc`](https://github.com/jdpalmer/modc) | Safe systems language that compiles via QBE |
| [`modc-qbe`](https://github.com/jdpalmer/qbe) | QBE fork with codegen fixes required by `modc` |
| [`transmute`](https://github.com/jdpalmer/transmute) | Convert image formats with Quartz |

## Updating

```bash
brew update
brew upgrade <formula>
```
